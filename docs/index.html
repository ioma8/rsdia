rsdia

A terminal editor for ASCII diagrams: draw boxes, arrows, lines and text with the mouse or the keyboard, and export the whole thing as plain text. One static binary — no runtime, no server, no account.

Install

Grab a binary for macOS, Linux or Windows (arm64 or x86_64) from the latest release, or build it: 

cargo install --git https://github.com/ioma8/rsdia

Use

1–6 · r v a l t e
box, select, arrow, line, text, eraser
drag
draw; f flips an elbow mid-drag
y x p
copy, cut, paste a selection; arrows nudge it, del erases it
ctrl+s o e
save, drawings list, export panel
alt+f e v h
the menus, walked with the arrows and enter
? esc
help, and close, cancel or deselect
ctrl+c
quit; the drawing is saved first

Where it keeps things

Drawings are .rd.json under ~/.local/share/rsdia, settings under ~/.config/rsdia, and they autosave. In tmux set set -g mouse on; on macOS use the bare digits instead of alt+digit.

The drawing logic is ported from ASCIIFlow (MIT, © Lewis Hemens) and stays byte-compatible with its fixtures. rsdia is MIT. Source · Releases
